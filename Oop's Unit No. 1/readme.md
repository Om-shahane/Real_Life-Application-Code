## 🧩 OOP Concepts Covered

### 1. Class and Object

Classes are used to create user-defined data types, while objects are instances of classes.

### 2. Encapsulation

Encapsulation combines data and functions into a single unit and provides controlled access to data.

### 3. Inheritance

Inheritance allows a derived class to acquire properties and behaviours from a base class.

### 4. Polymorphism

Polymorphism allows the same function or interface to behave differently in different situations.

### 5. Abstraction

Abstraction hides unnecessary implementation details and exposes only the required functionality.

### 6. Constructors

Constructors are special member functions used to initialize objects.

### 7. Function Overloading

Function overloading allows multiple functions with the same name but different parameters.

### 8. Function Overriding

Function overriding allows a derived class to provide its own implementation of a base-class function.

## ▶️ How to Run the Programs

### Step 1: Clone the Repository

```bash
git clone https://github.com/Om-shahane/Real_Life-Application-Code.git
```

### Step 2: Open the Repository

```bash
cd Real_Life-Application-Code
```

### Step 3: Select a Unit

For example:

```text
Oop's Unit No. 1
```

### Step 4: Open the C++ Program

Open the `.cpp` file using your preferred C++ IDE or editor.

### Step 5: Compile the Program

Using g++:

```bash
g++ program.cpp -o program
```

### Step 6: Run the Program

On Windows:

```bash
program.exe
```
